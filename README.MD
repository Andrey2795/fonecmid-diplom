*Все нижеперечисленные справочники, регистры и документы доступны в подсистеме "Добавленные объекты"

1)Для корректной работы системы оповещения документа "Обслуживание клиентов" необходимо создать группу и бота в Телеграмм.
Уведомления создаются при создании нового документа, а также при изменении даты/времени/ФИО специалиста.

2)Необходимо заполнить константы. После выполнения шага 1 заполним данные для системы оповещения. 
Для этого введем в "Токен управления телеграм - ботом (ВКМ)" и "Идентификатор группы для оповещения (ВКМ)" соответствующие значения.
Также заполним "Номенклатура абонентская плата (ВКМ)" и "Номенклатура работы специалиста (ВКМ)" элементами справочника номенклатура с видом услуги (при необходимости элементы нужно создать).

3)Нужно заполнить регистр сведений "Условия оплаты сотрудников (ВКМ)" указав процент от продаж у специалистов и оклады у всех сотрудников.

4)В справочник "Графики работы (ВКМ)" добавить вид графика работы (например, пятидневка). Далее, вызвать обработку "Заполнить график (ВКМ)". Указать в ней ранее созданный вид графика работы, выбрать период,
указать цифрами номера выходных дней (пример: 6,7 - Суббота,Воскресенье соответственно).

5)Создать всех необходимых пользователей в справочнике "пользователи" (они же будут являться сотрудниками). Назначить им соответствующие права, создав профили групп доступа.

6)Проинструктировать соответствующих сотрудников о следующем:

Бухгалтера, о возможности автоматического формирования документов по реализации с помощью обработки "Массовое создание актов (ВКМ)".

О необходимости заполнения всех вышеперечисленных констант.
